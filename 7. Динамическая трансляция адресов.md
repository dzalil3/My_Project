Для реализации динамической трансляция адресов нам нужно установить утилиту iptables на #ISP.  
*Пример команды iptables:*
*iptables -t nat -A POSTROUTING -o ens20 -s 172.16.5.0/28 -j MASQUERADE*
	1. `iptables` -  Утилита командной строки для настройки правил брандмауэра в Linux.
	2. `NAT (Network Address Translation)` -  Метод преобразования IP-адресов.
	3. `Цепочка POSTROUTING` -  Цепочка в таблице nat, применяемая после того, как пакет был маршрутизирован, но перед тем, как он будет отправлен из системы.
	4. `MASQUERADE` -  Специальная цель в iptables, используемая для NAT. Она динамически заменяет IP-адрес источника пакета на IP-адрес исходящего интерфейса.
	5. `Сохранение правил iptables` Правила, настроенные с помощью , по умолчанию не сохраняются после перезагрузки системы. Необходимо сохранить их в файл конфигурации.
	6. `iptables-save > /etc/sysconfig/iptables` - Сохранение настроек iptables
	7. `systemctl enable --now iptables.service` - Добавление в автозагрузку

==HQ-RTR==

```
en
	conf t 
	interface int1
		ip nat inside
		exit
	interface int2
		ip nat inside
		exit
	interface int0
		ip nat outside
		exit
	ip nat pool NAT_POOL 192.168.1.1-192.168.1.254,192.168.2.1-192.168.2.254
	ip nat source dynamic inside-to-outside pool NAT_POOL overload inerface int0
	write memory
	exit
ping 8.8.8.8
```

1. **`ip nat inside`**
    - Определяет интерфейс `int1` как “inside” для NAT. Это означает, что интерфейс подключен к внутренней сети, IP-адреса которой будут транслироваться.
2. **`ip nat outside`**
    - Определяет интерфейс `int0` как “outside” для NAT. Это означает, что интерфейс подключен к внешней сети (например, Интернету).
3. **`ip nat pool NAT_POOL 192.168.1.1-192.168.1.254,192.168.2.1-192.168.2.254`**
	- Создает пул IP-адресов NAT с именем `NAT_POOL`. Этот пул содержит два диапазона адресов: `192.168.1.1` - `192.168.1.254` и `192.168.2.1` - `192.168.2.254`. Эти адреса будут использоваться для трансляции адресов из внутренней сети.
4. **`ip nat source dynamic inside-to-outside pool NAT_POOL overload interface int0`**

	- Настраивает динамический `NAT`.
    - `dynamic`: Указывает, что NAT будет динамически назначать IP-адреса из пула `NAT_POOL`.
    - `inside-to-outside`: Указывает, что NAT будет применяться к трафику, идущему из внутренней сети во внешнюю.
    - `pool NAT_POOL`: Указывает, что IP-адреса для NAT будут выбираться из пула `NAT_POOL`.
    - `overload`: Включает PAT (Port Address Translation). Это позволяет нескольким устройствам во внутренней сети использовать один IP-адрес из пула, используя разные порты. Без `overload`, каждому устройству во внутренней сети потребуется свой уникальный IP-адрес из пула.

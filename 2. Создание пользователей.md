Во время создания учетных записей на AltLinux, создается пользователь sshuser с идентификатором `2026`, после чего задается пароль `P@ssw0rd`. Затем запускается файл редактирования sudo, где раскомментируется строчка, позволяющая пользователям, входящим в группу `wheel` выполнять через sudo любую команду с любого компьютера, не запрашивая их пароль.

==HQ-SRV==

```
useradd remote_user -u 2026
visudo
	WHEEL_USERS ALL=(ALL:ALL) NOPASSWD: ALL)
passwd remote_user
	P@ssw0rd
	P@ssw0rd
gpasswd -a "remote_user" wheel
```
1. `useradd sshuser -u 1010``
	Что делает: создаёт нового пользователя с именем `remote_user`.
	Опция `-u 2026` задаёт конкретный UID (идентификатор пользователя) — в данном случае 1010.
	Если не указать `-u`, системе будет назначен следующий свободный UID автоматически.
	2. `passwd sshuser`
	Запускает процесс установки или изменения пароля для пользователя `remote_user`.
	После ввода команды система попросит ввести новый пароль дважды для подтверждения.
	3. `visudo`
	Открывает файл конфигурации sudoers для редактирования.
	Используется именно эта команда, чтобы избежать ошибок синтаксиса, которые могут привести к потере доступа к sudo.
	Обычно открывается в редакторе vi или nano.


> Раскомментировать # WHEEL_USERS ALL=(ALL:ALL) NOPASSWD: ALL 
> (пример WHEEL_USERS ALL=(ALL:ALL) NOPASSWD: ALL) ]> ![[visudo.png]]

```
gpasswd -a "remote_user" wheel 
```

Такие же действия проводим и на #BR-SRV

==HQ-RTR== 

```
en
	conf t 
	username net_admin
	role admin
	password P@ssw0rd
	exit
write memory
```

Во время создания учетных записей на ecorouter, создается пользователь `net_admin`, после чего задается пароль `P@ssw0rd`. Затем, созданному ранее пользователю присваиваются привилегии администратора.
	1.  `username` - имя пользователя 
	2. `role admin` - выдача прав админа
	3. `password` - пароль

Такие же действия выполняем и на BR-RTR

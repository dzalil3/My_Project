**Виртуальный коммутатор** — это программный аналог физического сетевого свитча, который соединяет виртуальные машины и контейнеры в единую сеть, управляет трафиком между ними и интегрируется с физической инфраструктурой.
==HQ-RTR==

```
en
	conf t 
		interface int3
			descripton "999"
			ip address 192.168.99.1/29
			exit
		port te1
			service-instance te1/int3
			encapsulation dot1q 999
			rewrite pop 1
			exit
		interface int3
			connect port te1 service-instance te1/int3
			exit
		write memory
		end
```

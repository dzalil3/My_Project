
>Настройка безопасного SSH-доступа на серверах HQ-SRV и BR-SRV. Основные изменения включают смену порта SSH на 2024, ограничение доступа только для пользователя sshuser, установку лимита в две попытки входа и настройку предупреждающего баннера "Authorized access only".
	Для HQ-SRV конфигурация прописана в файле `/etc/openssh/sshd_config`, после изменений служба sshd перезапускается. Проверка подключения выполняется с маршрутизатора HQ-RTR командой `ssh remote_user@192.168.1.10 -p 2026`.
		Аналогичные настройки применяются для BR-SRV, но проверка осуществляется с BR-RTR на адрес 192.168.3.10. В обоих случаях используется пароль, заданный при создании учетной записи sshuser.


==HQ-SRV==
 
```
vim /etc/openssh/sshd_config
	Port 2026
	AllowUsers sshuser
	Maxauthtries 2
	PasswordAuthentication yes
	Banner /etc/openssh/banner
:wq
vim /etc/openssh/banner
	Authorized access only
:wq
```

>Проделываем такие же действия и на `BR-SRV`

==BR-RSV==

```
vim /etc/openssh/sshd_config
	Port 2026
	AllowUsers sshuser
	Maxauthtries 2
	PasswordAuthentication yes
	Banner /etc/openssh/banner
:wq
vim /etc/openssh/banner
	Authorized access only
:wq
```

*Объяснение:*
	1. **Port 2024** — SSH-сервер работает на нестандартном порту 2024 (вместо 22)
	2. **AllowUsers sshuser** — доступ только для пользователя _sshuser_ (все остальные блокируются)
	3. **MaxAuthTries 2** — максимум 2 попытки ввода пароля перед отключением
	4. **PasswordAuthentication yes** — разрешена аутентификация по паролю (менее безопасно, чем ключи)
	5. **Banner /etc/openssh/banner** — показывает пользовательский баннер из файла перед входом

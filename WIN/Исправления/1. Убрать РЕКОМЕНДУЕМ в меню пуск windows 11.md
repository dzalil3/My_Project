**Открой стандартный «Блокнот»** (нажми Пуск, введи слово _Блокнот_ и открой его) **Скопируй и вставь** в пустой документ ровно тот код, который ты нашел (включая самую первую пустую строку, это важно):

```Plaintext
Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\PolicyManager\current\device\Start]
"HideRecommendedSection"=dword:00000001

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\PolicyManager\current\device\Education]
"IsEducationEnvironment"=dword:00000001

[HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\Explorer]
"HideRecommendedSection"=dword:00000001
```

- В Блокноте нажми **Файл** -> **Сохранить как...**
    
- В открывшемся окне выбери место для сохранения (например, Рабочий стол).
    
- **Самый важный шаг:** В поле «Тип файла» (внизу окна сохранения) обязательно измени «Текстовые документы (_.txt)» на «Все файлы (_.*)». Если этого не сделать, файл сохранится как обычный текст и не сработает.
    
- В поле «Имя файла» напиши любое название, но обязательно добавь в конце расширение `.reg`. Например: `remove_recom.reg`
    
- Нажми **Сохранить**. На рабочем столе появится файл с иконкой из рассыпающихся синих кубиков (значок реестра).

*Создаём новую папку в на диске где установлена система и переносим созданный файл туда*
![](../../png/Pasted%20image%2020260724141201.png)
### Как применить созданный файл:

1. Кликни по сохраненному файлу два раза.
    
2. Система безопасности Windows (UAC) спросит, разрешаешь ли ты этому приложению вносить изменения — нажми **«Да»**.
    
3. Затем появится грозное предупреждение редактора реестра о том, что добавление сведений может повлиять на работу системы. Не пугайся, жми **«Да»**.
    
4. Появится сообщение об успешном внесении данных. Жми **«ОК»**.
    
5. **Перезагрузи компьютер**.

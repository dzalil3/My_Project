**С помощью стрелочек на клавиатуре или клавиши `Enter` выберите самый первый пункт — Install (Install pfSense)**.

![](../png/Pasted%20image%2020260804224547.png)
![](../png/Pasted%20image%2020260716124610.png)

**Стрелочкой «вниз» опустись на вторую строчку: T Pool Type/Disks: stripe: 0 disks Нажми `Enter` (или _Select_). Откроется окно со списком ваших дисков.**

![](../png/Pasted%20image%2020260716125235.png)

**Здесь выбирается тип RAID-массива. Так как у меня один жесткий диск, массив делать не нужно. Оставь выбранным самый первый пункт — stripe (Stripe - No Redundancy).**

![](../png/Pasted%20image%2020260716125322.png)

**Нажми пробел и выбери свой жёсткий диск для установки**

![](../png/Pasted%20image%2020260716125352.png)
![](../png/Pasted%20image%2020260716125433.png)

**Строчка изменилась на `stripe: 1 disk`, значит накопитель успешно выбран.**

![](../png/Pasted%20image%2020260716125517.png)

**Нажимаем `YES` чтобы начать установку**

![](../png/Pasted%20image%2020260716125628.png)
![](../png/Pasted%20image%2020260716125657.png)

**После завершения установки он попросит перезапуститься. Нажми `Reboot`**

![](../png/Pasted%20image%2020260716125740.png)

**После перезагрузки начнётся базовая настройка, тут он просит указать сетевую карту `WAN` для доступа к сети (в моём случаи `re0`)**

![](../png/Pasted%20image%2020260805154419.png)

**Пропускай эту строку нажав `Enter` если у тебя нету второй сетевой карты (в данный момент у меня небыло второго)**

![](../png/Pasted%20image%2020260716131123.png)
**Напиши `y` если согласен на то чтобы использовать `re0` в качестве сетевой карты `WAN`**

![](../png/Pasted%20image%2020260716131139.png)

**Для подключения и дальнейшей настройки PFsense проделываем следующие действия:**
```
ping 8.8.8.8 #Проверяем доступ к интернету
pfctl -d #Временно отключаем firewall чтобы роутер позволил к нему подключаться по ssh и веб интерфейсу
exit
```
**Для подключения по ssh с win указываем параметр `14` и нажимаем `y` тем самым включая ssh**
![](../png/Pasted%20image%2020260716131714.png)

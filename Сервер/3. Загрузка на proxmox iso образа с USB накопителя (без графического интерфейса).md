>1. *Находишь свой накопитель в списке (в моём случаии **sdd2**)
```shell
lsblk
```
<img src="../png/Pasted%20image%2020260710202516.png" width="498">
>2. Создаёшь место для монтирования usb накопителя
```shell
mkdir /mnt/usb #любое название
```
>3. Монтируешь
```shell
mount -o loop /dev/sdd2 /mnt/usb
```
> 4. Переходишь в паку монтирования
```shell
cd /mnt/usb
ls
```
*Ищешь нужный iso образ*
![](../png/Pasted%20image%2020260710203354.png)
>5. Копируешь её в proxmox по пути /var/lib/vz/template/iso/
```linux
cp debian-13.4.0-amd64-netinst.iso /var/lib/vz/template/iso/
```

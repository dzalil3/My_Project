
> 	Для создания интерфейса GRE-туннеля на ecorouter прописывается int tunnel.0, после чего интерфейсу назначается ip-адрес и выставляется параметр MTU: в связи с добавлением служебного заголовка появляются новые требования к допустимому значению MTU при передаче пакета. Заголовок GRE имеет размерность 4 байта, 20 байт транспортный IP заголовок, заголовок IP пакета 20 байт, таким образом возникает необходимость задавать размер допустимого MTU на интерфейсах туннеля меньше стандартного значения. Впоследствии задается режим работы туннеля GRE, адреса начала и конца туннеля и команда настройки аутентификации между маршрутизаторами ключом “ecorouter’

==HQ-RTR==

```
en
	conf t 
	interface tunnel.0
		ip address 172.16.0.1/30
		ip mtu 1400
		ip tunnel 172.16.1.2 172.16.2.2 mode gre
		ip ospf authentication-key ecorouter
		exit
	write memory
```

>Аналогичные действия выполняем и на #BR-RTR, но меняем ip - адрес и ip - tunnel

==BR-RTR==

```
en
	conf t 
	interface tunnel.0
		ip address 172.16.0.2/30
		ip mtu 1400
		ip tunnel 172.16.2.2 172.16.1.2 mode gre
		ip ospf authentication-key ecorouter
		exit
	write memory
```

*Объяснение:*
	1. **interface tunnel.0** — создает туннельный интерфейс с номером 0
	2. **ip address 172.16.0.1/30** — назначает туннелю IP-адрес с маской /30 (4 адреса)
	3. **ip mtu 1400** — устанавливает MTU 1400 байт для предотвращения фрагментации
	4. **ip tunnel 172.16.4.4 172.16.5.5 mode gre** — настраивает GRE-туннель между локальным адресом 172.16.4.4 и удаленным 172.16.5.5
	5. **ip ospf authentication-key ecorouter** — задает ключ **ecorouter** для аутентификации OSPF

Проведём базовую настройку всех устройств.
	Для открытия файла и его редактирования необходимо прописать `vim` и нужный путь (например: `vim /etc/net/sysctl.conf`) до файла, после чего, в открывшемся окне вписываются нужные параметры. 
	Для создания файла используется команда `mkdir` так же прописывается нужный путь (например: `mkdir /etc/net/ifaces/ens15`)

Для редактирования текстового редактора переходим в режим `INSERT` нажав на клавишу `I`
или `Insert`.  Чтобы выйти и сохранить содержимое в текстовом редакторе нужно нажать клавишу `esc` и прописать `:wq`, если не хотите сохранять содержимое, то нужно прописать `q!`. 

==ISP==

```
mkdir /etc/net/ifaces/ens20
mkdir /etc/net/ifaces/ens21
mkdir /etc/net/ifaces/ens22
```

После создания нужных нам файлов, нужно их настроить:
```
vim /etc/net/ifaces/ens20/options
	BOOTPROTO=dhcp
	CONFIG_IPV4=yes
	DISABLED=no
	TYPE=eth
```

Чтобы  не прописывать эти же настройки на других интерфейсах можно использовать команду `cp`, но на интерфейсах `ens21` и `ens22` нужно использовать статические ip-адреса.

```
cp /etc/net/ifaces/ens20/options /etc/net/ifaces/ens21/options
cp /etc/net/ifaces/ens20/options /etc/net/ifaces/ens22/options
vim /etc/net/ifaces/ens21/options
	BOOTPROTO=static
	CONFIG_IPV4=yes
	DISABLED=no
	TYPE=eth
	:wq
systemctl restart network

vim /etc/net/ifaces/ens22/options
	BOOTPROTO=static
	CONFIG_IPV4=yes
	DISABLED=no
	TYPE=eth
	:wq
systemctl restart network
```

`systemctl restart network` - перезапуск службы сети

Так же нужно задать ip-адреса и маски интерфейсам:

```
vim /etc/net/ifaces/ens21/ipv4address
	172.16.1.1/28
vim /etc/net/ifaces/ens22/ipv4address
	172.16.2.1/28
```

Не забываем включать пересылку пакетов. Для этого проделываем проходим по следующему пути: `vim /etc/net/sysctl.conf` и редактируем строчку `net.ipv4.ip_forward = 0`
и меняем цифру `0` на `1` (`net.ipv4.ip_forward = 1`)

Для настройки ecorouter, необходимо войти в привилегированный режим, командой ``en``, после чего войти в режим глобальной конфигурации, командой ``conf t``. Будут созданы интерфейсы, после чего им будет присвоено описание и IP-адрес.
	`interface int 0` - Эта команда выбирает интерфейс с именем `int0` для последующей настройки.
	`description "to isp"` - то команда описывающая к какому интерфейсу подключен какой либо интерфейс.
	`ip address 172.16.4.4/28` - Назначает интерфейсу `int0` IP-адрес `172.16.4.4` и маску подсети `/28` (что соответствует `255.255.255.240`).
	`exit` - выход из какого либо интерфейса или порта
	`port te0` - Переходит в режим настройки порта `te0`.
	`service-instance te0/int0` - Создает service instance, привязанный к порту `te0` и, предположительно, связанный с трафиком, проходящим через `int0`. 
	`encapsulation untagged` - указывает, что трафик, проходящий через этот сервисный экземпляр, не должен иметь тегов VLAN (т.е., это “обычный” трафик без VLAN).
	`connect port te0 service-instance te0/int0` - создает или выбирает логический сервис instance с именем `te0/int0` на физическом порту `te0`. После выполнения этой команды, дальнейшие команды конфигурации будут применяться именно к этому service instance `te0/int0`, а не ко всему физическому порту `te0`.
	`ip route 0.0.0.0 0.0.0.0 172.16.4.0` - Эта команда указывает маршрутизатору отправлять весь трафик, предназначенный для любых сетей, для которых нет более конкретных маршрутов, на устройство 


==HQ-RTR==


```
en
	conf t 
		interface int0
			description "to isp"
			ip address 172.16.1.2/28
			exit
		port te0
			service-instance te0/int0
			encapsulation untagged
			exit
		interface int0
			connect port te0 service-instance te0/int0
		interface int1
			description "to hq-srv"
			ip address 192.168.1.1/27
			exit
		interface int2 
			descriptions "to hq-cli"
			ip address 192.168.2.1/28
			exit
		port te1
			service-instance te1/int1
				encapsulation dot1q 100
				rewrite pop 1
				exit
			service-instance te1/int2
				encapsulation dot1q 200
				rewrite pop 1
				exit
				exit
		interface int1 
			connect port te1 service-instance te1/int1
			exit
		interface int2
			connect port te1 service-instance te1/int2
		ip route 0.0.0.0 0.0.0.0 172.16.1.1
write memory
```

Проводим аналогичные действия как на #ISP c #HQ-SRV, #HQ-CLI и #BR-SRV:

`/etc/net/ifaces/ens20/ipv4route` - это файл который определяет шлюз по умолчанию для интерфейса `ens20`. `default via 192.168.1.1`: Это означает, что любой трафик, предназначенный для сетей, отличных от локальной сети `192.168.1.0/26`, должен быть отправлен на IP-адрес `192.168.1.1`. `192.168.1.1` выступает в качестве шлюза по умолчанию (router). Когда ваш компьютер хочет связаться с хостом за пределами локальной сети (например, google.com), он отправляет пакеты на `192.168.1.1`, который затем пересылает их дальше (предположительно, это ваш роутер или другой сетевой узел, имеющий доступ к интернету).

==HQ-SRV==
```
mkdir /etc/net/ifaces/ens20
vim /etc/net/ifaces/ens20/options
	BOOTPROTO=static
	CONFIG_IPV4=yes
	DISABLED=no
	TYPE=eth
	:wq
vim /etc/net/ifaces/ens20/ipv4address
	192.168.1.10/27
	:wq
vim /etc/net/ifaces/ens20/ipv4route
	default via 192.168.1.1
	:wq
systemctl restart network
```

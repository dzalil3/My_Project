
*Разбор команд*
	1. `timedatectl`: Утилита в Linux для управления временем и датой.
	2. `set-timezone Asia/Yekaterinburg`: Устанавливает часовой пояс системы.
	3. `Asia/Yekaterinburg`. Это обновит системное время и настройки часового пояса.
	ecorouter:
		1. **`ntp timezone utc+5`**`ntp`: Относится к настройке Network Time Protocol (NTP). NTP используется для синхронизации времени устройства с NTP-сервером.
		2. `timezone utc+5`: Устанавливает смещение часового пояса относительно UTC (Coordinated Universal Time) на +5 часов.


==HQ-SRV==

```
timedatectl set-timezone Asia/Yekaterinburg
timedatectl
```

==HQ-CLI==

```
timedatectl set-timezone Asia/Yekaterinburg
timedatectl
```

==BR-SRV==

```
timedatectl set-timezone Asia/Yekaterinburg
timedatectl
```

==ISP==
На #ISP  нужно обновить базу данных часовых поясов `tzdata`, но перед этим обновить пакеты.

```
apt-get update 
apt-get resinstall tzdata
timedatectl set-timezone Asia/Yekaterinburg
timedatectl
```

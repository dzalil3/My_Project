Настройка SSH на pfSense имеет два важных этапа: **включение сервера** (чтобы к роутеру можно было подключиться) и **настройка правил файрвола** (если подключаетесь из WAN/интернета).

Вот пошаговая инструкция от входа в веб-интерфейс до консольной команды.

### Этап 1: Включение SSH в веб-интерфейсе

1. Зайдите в **System** → **Advanced** → вкладка **Admin Access**.
    
2. В блоке **Secure Shell** установите галочку **Enable Secure Shell**.
    
3. **Важно:** Рекомендую сменить порт по умолчанию (22) на что-то нестандартное (например, `2222` или `4022`), особенно если планируете открывать доступ из интернета. Это резко сократит количество атак ботов.

auto enp0s3
iface enp0s3 inet static
    address 192.168.1.11
    netmask 255.255.255.0
    gateway 192.168.1.1
    dns-nameservers 8.8.8.8 8.8.4.4
